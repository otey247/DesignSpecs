# Conference Presentation Design Specification

## Overview
Engaging and memorable presentation design for conferences, keynotes, public speaking, and large audience presentations.

## Design Principles
- **Visibility**: Readable from the back of large venues
- **Engaging**: Hold audience attention throughout
- **Memorable**: Create lasting impressions
- **Shareable**: Slides that work well in photos and social media

## Color Palette
- **Bold Backgrounds**: Dark or vibrant backgrounds for impact
  - Dark: #000000, #1A1A1A, Deep navy
  - Vibrant: Brand colors, gradients
- **High Contrast Text**: White or bright colors on dark backgrounds
- **Accent Colors**: Bright, energetic colors for emphasis
- **Consistency**: Stick to 3-4 colors maximum

## Typography
- **Headings**: Extra large, bold fonts for visibility
  - Title/Quote: 64-120pt, Extra Bold
  - Section Headers: 44-56pt, Bold
  - Body Text: 32-40pt, Regular
- **Font Choice**: Sans-serif for readability from distance
- **Avoid**: Small text, cursive fonts, low-contrast combinations

## Layout Guidelines
- **Minimal Text**: Large text, few words per slide
- **Full-Bleed**: Use entire slide space
- **Centered**: Often works best for large screens
- **Single Focus**: One clear element per slide
- **Edge Safety**: Keep important content away from edges

## Slide Structure
1. **Title Slide**: Conference logo, talk title, speaker name, Twitter/social handles
2. **Introduction**: Who you are (briefly)
3. **Hook**: Compelling opening (statistic, question, story)
4. **Main Content**: Core message in clear sections
5. **Key Takeaways**: 3-5 memorable points
6. **Call-to-Action**: What audience should do next
7. **Thank You/Contact**: Social media, website, contact info
8. **Q&A**: Simple slide prompting questions

## Visual Elements
- **Full-Screen Images**: High-impact, relevant photos
- **Large Text Quotes**: Pull quotes and key messages
- **Simple Icons**: Oversized, minimal icons
- **Data Visualization**: Simple, clear charts
- **GIFs/Animations**: Strategic use for emphasis or humor
- **Videos**: Short clips embedded or transitioned to
- **Live Demos**: Screenshots or actual demonstrations

## Content Strategy
- **One Concept Per Slide**: Don't overload
- **Visual-First**: Image with minimal text overlay
- **Progressive Disclosure**: Build complex ideas gradually
- **Storytelling**: Create narrative arc
- **Repetition**: Reinforce key messages
- **Contrast**: Alternate between dense and minimal slides

## Best Practices
- Use presenter notes heavily (slides are visual aids)
- Test slides on large screen/projector
- Include slide numbers (helps with Q&A)
- Avoid busy backgrounds
- Use high-resolution images only (300 DPI minimum)
- Create "title slides" for section breaks
- Include Twitter handles and hashtags for social sharing
- Time your presentation (1-2 minutes per slide)
- Practice with clicker/remote

## Engagement Techniques
- Ask questions to audience
- Include interactive polls
- Show real-world examples
- Use humor appropriately
- Tell personal stories
- Include surprising facts
- Create "tweetable" moments
- Use callbacks and references

## Technical Considerations
- **Aspect Ratio**: 16:9 standard for most venues
  - Check with organizers beforehand
- **Resolution**: 1920x1080 minimum, 4K for large venues
- **Video Format**: MP4 with embedded codecs
- **Fonts**: Embed or use system fonts
- **Backup**: PDF version as fallback
- **File Size**: Keep reasonable for conference systems

## Accessibility for Large Venues
- Extra large text (minimum 32pt body text)
- Extreme contrast ratios (7:1 or higher)
- Avoid red/green combinations
- Provide handouts or slides online
- Use microphone (even in small rooms)
- Describe visual content verbally

## Social Media Optimization
- Include Twitter handle and hashtag on every slide
- Create quotable slides (large text, clean background)
- Use conference hashtag
- Design for photo sharing
- Include memorable visuals
- Add QR codes for resources

## Presentation Types

### Keynote (30-60 minutes)
- More storytelling and inspiration
- Big ideas and vision
- High production value
- Emotional connection

### Technical Talk (20-45 minutes)
- Balance slides with live demos
- Include code/technical details
- Provide resources and links
- Focus on learning outcomes

### Lightning Talk (5-10 minutes)
- Minimal slides (10-15 max)
- Fast-paced
- One core message
- Strong opening and closing

### Panel Presentation
- Minimal slides (topic prompts)
- Focus on discussion
- Include panelist names and bios

## Common Mistakes to Avoid
- Reading directly from slides
- Too much text on slides
- Low-contrast text
- Small fonts
- Overusing animations
- Skipping testing on venue equipment
- No backup plan
- Ignoring time limits
- Complex charts or diagrams

## Pre-Conference Checklist
- Test presentation on venue equipment
- Verify aspect ratio compatibility
- Check font rendering
- Test videos and animations
- Bring backup on USB drive
- Have PDF version ready
- Test remote/clicker
- Verify internet connectivity needs
- Practice timing
- Prepare for Q&A

## File Requirements
- **Format**: .pptx (with embedded fonts and media)
- **Resolution**: 1920x1080 or higher
- **Backup**: PDF version without animations
- **Assets**: Keep high-res originals separate
- **Naming Convention**: `Conference_TalkTitle_Speaker_Date.pptx`

## Post-Conference
- Share slides on SlideShare, Speaker Deck, or personal website
- Include contact and social media info on shared version
- Add links to resources mentioned
- Consider adding notes/explanations for online viewers
- Engage with attendees on social media
