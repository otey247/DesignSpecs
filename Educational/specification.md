# Educational Presentation Design Specification

## Overview
Engaging and informative presentation design for lectures, training sessions, workshops, and educational content delivery.

## Design Principles
- **Clarity**: Information should be easy to understand and digest
- **Engagement**: Use visual elements to maintain student interest
- **Accessibility**: Consider diverse learning styles and needs
- **Progressive**: Build concepts incrementally

## Color Palette
- **Primary Colors**: Warm, inviting tones (blues, greens, oranges)
- **Background**: Light, non-distracting colors (#FFFFFF, #F0F8FF)
- **Text**: High contrast for readability (#333333 on light backgrounds)
- **Highlights**: Bright accent colors for key points (yellow, orange)

## Typography
- **Headings**: Clear, legible sans-serif fonts
  - Title: 40-44pt, Bold
  - Section Headers: 32-36pt, Bold
  - Subsections: 24-28pt, Semi-bold
- **Body Text**: 20-24pt, Regular (larger for visibility)
- **Code/Examples**: Monospace fonts (Courier New, Consolas) 16-18pt

## Layout Guidelines
- **Margins**: Minimum 0.75" on all sides for projection visibility
- **Information Density**: Don't overcrowd slides
- **Visual Hierarchy**: Clear progression from most to least important
- **Consistency**: Same layout for similar content types

## Slide Structure
1. **Title Slide**: Course name, topic, instructor name, institution logo
2. **Learning Objectives**: What students will learn
3. **Content Slides**: One concept per slide
4. **Examples/Demonstrations**: Practical applications
5. **Review/Summary**: Key takeaways
6. **Questions Slide**: Encourage interaction

## Visual Elements
- **Diagrams**: Simplified illustrations of complex concepts
- **Flowcharts**: Show processes and relationships
- **Images**: Relevant, educational, properly cited
- **Infographics**: Summarize information visually
- **Videos**: Embed short clips for demonstrations
- **Interactive Elements**: Polls, quizzes, discussion prompts

## Best Practices
- Use progressive disclosure for complex topics
- Include real-world examples and case studies
- Add speaker notes for teaching guidance
- Use consistent color coding for categories
- Include references and sources
- Build in interactive checkpoints
- Use analogies and metaphors visually

## Accessibility Considerations
- Minimum font size: 20pt
- High contrast ratios (4.5:1 minimum)
- Alt text for images
- Avoid relying solely on color to convey information
- Use clear, simple language
- Provide transcripts for videos

## File Requirements
- **Format**: .pptx with embedded media
- **Resolution**: 1920x1080 (16:9 aspect ratio)
- **Compatibility**: Test on presentation systems
- **Backup**: PDF version without animations
- **Naming Convention**: `Course_Module_Topic_Date.pptx`
